## ✨ About the Project

**Sanskriti** is a front-end web development project designed to showcase
Indian festivals, cultural landmarks, and traditional art forms through
an attractive and interactive website.

The project demonstrates the use of HTML, CSS, and JavaScript to create
a user-friendly cultural experience.

## 🚀 Features

- 🪔 **Festival Explorer** – Explore popular Indian festivals.
- 🏛️ **Cultural Heritage** – Discover famous monuments and traditional art forms.
- 🔍 **Search Functionality** – Find festivals by name.
- 🎯 **Festival Filters** – Filter festivals by region.
- ⏳ **Festival Countdown** – Display a countdown to an upcoming festival.
- 🧠 **Cultural Quiz** – Test your knowledge of Indian culture.
- 💌 **Greeting Card Maker** – Create festive greeting cards.
- 📱 **Responsive Layout** – Designed to work across different screen sizes.
- 🎨 **Modern Design** – Includes attractive colours, hover effects, and animations.
